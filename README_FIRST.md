# NECUZAH Foundation Pack

This adds the first shared architecture without replacing your existing working homepage or root-level activities.

## Safe installation
1. Download and extract this ZIP.
2. Upload the included folders/files into the root of `necfamily/necuzah` on GitHub.
3. Keep your current `index.html`, root `rod-training.html`, `NECUZAH_Adventure_Connected_v2.html`, and `NECUZAH_Talking_Hybrid_Abacus_v5.html` unchanged.
4. If GitHub says a file will be overwritten, stop and check before committing.
5. Test `https://necfamily.github.io/necuzah/adventure-map.html` and a practice page.

Progress is currently stored in the browser on that device. Cross-device sync needs a shared database later. The new pages are a foundation; they do not yet replace the established root modules.
