One system. Different paths for every learner.

This prototype brings the first paths into one place. Unit-rod addition, subtraction and sequences have separate progress records. Higher place values and advanced operations are mapped here but will be implemented as their own tested modules.

2. Independent skill progress

3. Validated question engine

4. Learning + adventure

Teaching, practice, speech and rewards share the same skill engine.
